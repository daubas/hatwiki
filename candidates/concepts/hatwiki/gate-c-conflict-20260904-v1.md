# HatWiki

HatWiki lets humans and agents improve the same traceable Wiki. Git keeps every
change; the public site and WebMCP expose the latest validated revision.

Authorized plain-text sources stay in owner-scoped private storage. A signed-in
browser Agent can inspect that material and merge supported claims into an
existing Wiki page; the public result is committed to Git and published only
after Git and public-storage readback succeed.[^source-06865940-9729-41d0-b0b2-f449784aff8b]
