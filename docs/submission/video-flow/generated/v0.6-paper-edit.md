## Chapter 03 — Inspect, authorize, and durable publish

> Group label only; review the Editorial Beats below.

### Beat beat-03

Teaching purpose: Make the pre-write inspection, publication declaration, cited write, and durable revision visible in one continuous sequence.

Spoken content:
> Use inspect_changes to review the affected page, citations, WikiLinks, and unresolved markers before submitting anything. Propose one small clarification, then show the participant's explicit declaration that they may publish it. edit_page submits the cited change; the server validates it, returns a Git commit receipt, and makes the committed content available in the public R2 snapshot. Repeating the same request returns its original receipt instead of another write.
